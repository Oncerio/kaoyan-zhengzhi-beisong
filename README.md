一个离线可用的「背诵打卡 + 掌握度统计 + 薄弱点针对性复习」网页小工具，帮你把关《冲刺背诵手册》下册的背诵情况。

## 即点即用（三种方式任选）

**🌐 方式 A：网页版（最省事，点开链接就能用）**

> https://oncerio.github.io/kaoyan-zhengzhi-beisong/

手机、平板、电脑浏览器直接打开即可，无需下载、无需安装。进度保存在当前浏览器里。

**🛠 方式 C：源码版**

保持 `index.html` 与 `question_bank.js` 在同一文件夹，双击 `index.html`。

## 常见问题（重要）

**如果打开后一直停在「加载中…」出不来**，通常是文件被某个「预览窗口」打开、而该预览禁用了网页脚本导致的。请这样做：

1. 把 `考研政治背诵自测过关工具.html` **下载到本地**（例如桌面）。
2. 用鼠标**双击**它，让它用系统默认浏览器（Chrome / Edge 等）打开；或右键 →「打开方式」→ 选择 Chrome 或 Edge。
3. 若在浏览器里仍异常，页面顶部会出现**红色错误提示条**，把上面的文字发给我即可定位。

> 不要用某些聊天/网盘的「在线预览」打开 HTML，那里面脚本不会运行。

## 功能

- **总览**：题目总数、已掌握数、分科掌握进度条。
- **背诵**：先默背，在输入框**填写答案** → 点「✅ 提交判定」**自动判对错**并记录掌握度；或点「直接看答案」后手动自评。
- **随机抽查**：随机抽 20 题打乱顺序。
- **薄弱强化**：只考「掌握等级 < 4」的题，按最薄弱优先排序。
- **错题本**：自动收集评为「忘了/模糊」且未掌握的题，攻克后自动移出。
- **统计**：掌握等级分布、分科掌握率、累计作答与自评记得率。
- **设置**：导出/导入进度、重置进度。

## 掌握度规则

每道题有 0–5 级掌握度：

| 判定方式 | 等级变化 | 说明 |
|----------|----------|------|
| 提交判定：全对 | +1（最高 5） | 达到 4 级视为「已掌握」 |
| 提交判定：对一半及以上 | −1（最低 0） | 记为「模糊」 |
| 提交判定：对不到一半 | 归零 | 记为「忘了」，错次数 +1 |
| 直接看答案后自评 | 记得 +1 / 模糊 −1 / 忘了归零 | 手动自评 |

> 提交判定会逐空显示 ✅ / ❌ 和正确答案；按空格或 → 进入下一题。

## 快捷键（背诵页）

- 输入框内 `Ctrl + Enter`：提交判定
- 判定结果页 `空格` 或 `→`：下一题
- 「直接看答案」后 `1 / 2 / 3`：自评 记得 / 模糊 / 忘了
- `←`：回到上一题

## 题库说明

- 题目来自《背练结合·自测本》（30 天计划，共 **150 道填空题**）。
- 答案来自《冲刺背诵手册·下册》对应内容。
- 分 8 个板块：重要会议总结、重要人物及文献总结、重要土地政策总结、重要思想解放总结、马原、新思想、史纲、思修。
- 数据由 PDF 扫描件 OCR 后整理，已做去错字处理，个别字词如与纸质书有出入，以纸质书为准。
